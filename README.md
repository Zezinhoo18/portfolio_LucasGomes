# Portfolio BTS SIO SISR — Lucas Gomes

Version claire et minimaliste, sans photos.

## Lancer le site

1. Ouvre le dossier dans Visual Studio Code.
2. Installe l'extension **Live Server**.
3. Clique droit sur `index.html`.
4. Choisis **Open with Live Server**.

## Fichiers

- `index.html` : contenu
- `assets/css/style.css` : design
- `assets/js/script.js` : filtres, animations, modales
- `documents/` : CV, E5, E6, certifications

## À modifier

Dans `index.html` :

- ton adresse e-mail
- ton LinkedIn
- ton GitHub
- le nom et la présentation de ton entreprise
- tes certifications
- ton thème de veille
- tes réalisations E5/E6
- tes projets définitifs

Place ton CV sous :

`documents/CV-Lucas-Gomes.pdf`

## Hébergement

Le site est compatible avec GitHub Pages et n'utilise aucune base de données.
